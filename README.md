# Flappy Bird

Un clone del famoso gioco Flappy Bird sviluppato in Python.

## Descrizione

Controlla l'uccellino e cerca di attraversare il maggior numero possibile di tubi senza colpirli. Ogni tubo superato aumenta il punteggio.

## Caratteristiche

* Grafica 2D
* Sistema di punteggio
* Collisioni con tubi e terreno
* Schermata Game Over
* Riavvio della partita
* Supporto per effetti sonori

## Requisiti

* Python 3.10 o superiore
* Pygame

## Installazione

Installare Pygame:

```bash
pip install pygame
```

Avviare il gioco:

```bash
python main.py
```

## Controlli

* Barra spaziatrice: salto
* R: riavvia il gioco
